# Project 02 – Login & Signup Page

A beginner-friendly responsive Login and Signup page built using **HTML5 and CSS3**.

## Features

- Login form with email and password fields
- Signup form with name, email, password, and confirm password fields
- Remember Me checkbox
- Forgot Password link (UI only)
- Continue with Google button (UI only)
- Responsive layout for smaller screens
- Hover and focus effects

## Technologies Used

- HTML5
- CSS3

## Project Structure

```text
Project-02/
├── index.html
├── style.css
└── README.md
```

## How to Run

1. Download or copy the project files into a folder named `Project-02`.
2. Open the folder in Visual Studio Code.
3. Make sure `index.html` and `style.css` are in the same folder.
4. Open `index.html` in a browser, or use the **Live Server** extension in VS Code.
5. To use Live Server, right-click `index.html` and select **Open with Live Server**.

## How It Works

- The HTML file contains the login and signup form structure.
- The CSS file controls the layout, colors, spacing, buttons, shadows, and responsive design.
- The **Sign Up** link jumps to the signup form.
- The **Login** link points back to the top of the page.

## Important Notes

This project is a **frontend UI design only**.

- Forms do not create or verify user accounts.
- The Login and Create Account buttons do not authenticate users.
- Forgot Password and Google sign-in are visual links/buttons only.
- A working authentication system requires JavaScript and a backend/database or an authentication service.
